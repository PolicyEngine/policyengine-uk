# Housing Benefit

The default `housing_benefit_applicable_amount` calculation includes an adult
personal allowance and selected premiums. It omits ordinary child personal
allowances, including in periods when no two-child restriction applied.

See [historical child personal allowances and the deferred implementation](../../../../../docs/book/assumptions/housing-benefit-child-allowances.md)
for the Great Britain and Northern Ireland rules, individual-child protection,
Child Tax Credit assessment requirements and the missing historical facts.
The documentation adds no model input or calculation. Child disability and
protected family premiums remain separate work.
