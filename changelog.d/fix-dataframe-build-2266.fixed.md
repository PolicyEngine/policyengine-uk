- Fixed `Simulation(dataset=<DataFrame>)` for frames in which a benefit unit or household has more than one person. Each benefit unit and household now takes the value on its members' rows, single-person groups no longer take each other's values when the rows are not in identifier order, identifier columns are matched by exact name, and the simulation's `dataset` holds the multi-year dataset the frame describes. Frames whose identifier columns contradict each other, repeat a person, or name groups only with 32-bit float identifiers of 2**24 or more are refused instead of merging households.
