Uprate `water_and_sewerage_charges`, `housing_service_charges` and `pension_contributions_via_salary_sacrifice`, which declared an uprating index but were absent from `uprating_indices.yaml` and so were never uprated. Adds a code-health test asserting that every variable declaring `uprating` appears in that file under the matching index, so the gap fails at the point it is introduced. The test caught seven more on current main, now listed under the indices they declare: `cash_isa`, `stocks_and_shares_isa`, `mortgage_debt`, `consumer_debt`, `rent_paid_as_boarder`, `rent_paid_as_lodger` and `self_employment_gross_receipts`. None is yet a column in the released dataset, so they change no current output. `rail_usage` is deliberately excluded: its declared index is a cumulative level rather than a year-on-year rate. The three energy variables stay excluded because they are stored at the data build's own price level (#1867).
