- Economic assumption indices now run to the last year the growth series cover (2074) instead of stopping at 2039, so the State Pension and every other parameter uprated by an index keep growing after 2039 rather than freezing at their 2039 level. Fiscal-year conversion no longer stops at 2040: it rewrites only the years whose value changes, which leaves every value on every date as writing each year would and makes the parameter tree smaller and quicker to build. The LHA freeze anchor now reads the freeze parameter a year at a time, so a run of unfrozen years anchors on its last year however the values are stored.
