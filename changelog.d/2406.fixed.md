- A sum of scenarios keeps each part's timing. A part applied before data load, such as `no_economic_assumptions`, is still applied before it when added to a reform, so `no_economic_assumptions + reform` freezes the data as well as the parameters, and the sum of a macro scenario applied before data load and a reform projects the data with the macro growth. Parts applied after data load, including modifiers that edit the data, still run after it. The sum's fields still hold the whole sum. `Scenario.parts_by_data_load()` returns the two parts.
